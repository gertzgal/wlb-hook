# wlb-hook

Work-life-balance Claude Code hook plugin. Glossary in `CONTEXT.md`; use its terms.

## Planning tracker
Wayfinder map and tickets live outside the repo at `~/Projects/wlb-hook-tasks/` (`map.md`, `tickets/`).
Read `map.md` before starting work; claim a ticket by setting its `assignee`, resolve by appending `## Resolution`,
setting `status: closed`, and adding a line to the map's Decisions so far. See its README for the frontier query.

## Dev
`make check` (lint + validate + tests), `make demo`, `make smoke`, `make seed` (see README).
